## Launcher refactor finished + shipped-zip verification

Implemented the 3 agreed changes: all 4 launchers are now thin resolvers that
exec `scripts/bootstrap.py`; the checker enforces delegation + no-private-copies
+ a single GPU-advice owner; docs finally mention the portable pair.

Bugs found while verifying (all fixed):

1. `start.cmd` quoted `"%PYEXE%"` where `PYEXE="py -3"` — cmd.exe would look for
   a program literally named `py -3`. Fixed to unquoted `%PYEXE%`. Added check 9
   to `check_launchers.py` so it cannot come back.
2. bootstrap printed `[1/6] Checking for Python` a second time after the launcher
   had already done it. Launchers now say `Locating Python...`, unnumbered.
3. The GPU advice was printed with an inline `# and: pip uninstall ...`, which is
   not a comment to cmd.exe — the reader would paste a broken command. bootstrap
   now splits on `#` and prints each as its own runnable line.
