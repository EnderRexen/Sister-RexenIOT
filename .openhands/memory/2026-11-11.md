# 2026-11-11

## ComfyUI: provisioning, verification, and media generalization

Working on `sri/` (branch `security/api-token`). Goal: make ComfyUI actually
work locally, and cut the fixed per-turn token cost.

### The core insight: a workflow file is not an install

A ComfyUI workflow JSON names node *classes* (`SaveAudio`, `ACEStepSampler`)
that exist only once the node pack providing them is loaded, and it loads
checkpoints by *filename* that must be on disk. Dropping `audio.json` into
`data/workflows/` therefore does nothing by itself. Two consequences drove the
work:

1. **Startup verification** (`comfyui_provision.verify`): GET ComfyUI's
   `/object_info` (every class it actually offers) and diff it against
   `required_classes()` for each installed workflow plus the built-in image
   graph. Logged at boot. Read-only, always runs, no network cost beyond one
   call. A *directory* existing in `custom_nodes/` is not proof the pack
   loaded -- its requirements may have failed -- so asking the running server
   is the only dependable check. This is the thing that was missing.
2. **Startup provisioning** (`verify_and_provision`): opt-in, empty by default
   because it fetches GBs. `tools.comfyui_nodes` (git clone into
   `custom_nodes/` + `pip install -r requirements.txt`) and
   `tools.comfyui_models` (huggingface_hub download into `models/<subdir>/`).

### Bugs found and fixed

- `generate_image` -> `generate_media` with a `kind` param (image/audio/video/
  3d). Skill records are persisted in `data/skills.json`, so a rename needs a
  migration or the operator silently loses the capability: `_RENAMED_TOOLS`
  map in `app/skills.py`, applied in `load()`, idempotent.
- `_collect_images` read only the `images` key. A music/video workflow ends in
  `SaveAudio`/`VHS_VideoCombine`, which report under `audio`/`gifs`/`video`, so
  a *successful* generation handed back an empty list -- indistinguishable from
  "nothing generated". Now `_collect_outputs` over `_FILE_KEYS`.
- **`_inject_prompt` silently substituted the built-in image graph** for any
  workflow with no text node. Correct for images, badly wrong for audio: an
  audio request would submit an image graph and return a *picture of the song
  request*. Now guarded on `kind` and raises for non-image.
- ComfyUI filenames can contain spaces and `&`; the `/view?filename=...` URL
  was built by f-string interpolation, which truncates the query. Now
  `urlencode`.
- `_install_node` hardcoded `ROOT/.venv/bin/python` for `pip install -r`. That
  path does not exist on a Nix or system install. Now `sys.executable`.

### Token cost

Fixed per-turn cost (system prompt + all tool schemas) was ~1841 tok. Removed
the duplicated tool-name list from `build_system_prompt` (schemas already carry
every name -- listing them again paid twice, and a weaker local model would
sometimes *name* a tool instead of calling it) and trimmed verbose tool
descriptions. Now ~1667 tok, **-174/turn**, while `generate_media` covers four
modalities instead of one. Measure with the fixed prompt + `json.dumps` of
`[t.schema() for t in usable_tools(cfg)]`; 4 chars/tok is close enough.

### Sandbox traps hit again

- **`REXENIOT_HOME` relocates the whole app root**, so config is
  `$HOME/data/config.json`, not `$HOME/config.json`. `config.ROOT`, `DATA_DIR`
  and `CONFIG_PATH` are resolved at *import* time, so a test that sets the env
  var after `import app.config` (or reassigns `config.DATA_DIR`) changes
  nothing -- it must set it before the first app import.
- A test that writes a `comfyui_url` into a *shared* home breaks
  `test_reasoning_and_gating` (which asserts ComfyUI is withheld when no URL is
  configured). It looked like a regression from the rename; it was cross-test
  pollution. Each test needs its own `REXENIOT_HOME`.
- A loop running many test scripts against one shared `REXENIOT_HOME` hangs on
  the server tests (port/state collision). Isolate per test.
- `pip install`ed deps vanish between sessions -- reinstall
  pydantic/fastapi/httpx/psutil/numpy before running tests.
- `/tmp` is wiped between sessions; keep helper scripts in the repo or recreate.
- The terminal tool rejects a heredoc combined with a background `&` as
  "multiple commands"; write the script to a file and run that.

node/model `missing()` diff, the rename migration, multi-kind output
